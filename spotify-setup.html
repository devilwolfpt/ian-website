Spotify presence

Mostra o que estás a ouvir agora.

Liga a tua conta Spotify para o widget mostrar a música real, o artista e o estado de reprodução. A autorização acontece no Spotify.

01

Cria uma aplicação Spotify

Abre o Spotify for Developers, entra na tua conta e escolhe Create app.

02

Adiciona o endereço de retorno

Nas definições da aplicação, adiciona o endereço HTTP onde este site está a correr, por exemplo http://localhost:5500/index.html.

03

Copia apenas o Client ID

Cola aqui o Client ID público. Nunca é necessário inserir a tua palavra-passe nem um Client Secret.

Privacidade: o Client ID fica guardado apenas neste navegador. A sessão é autorizada diretamente pelo Spotify através de OAuth PKCE.
